## Rotator mechanics
- .rotator: display inline-grid. All items share one cell (grid-area: 1 / 1) so width = longest phrase. No layout shift.
- Inactive items: opacity 0, translateY(0.4em), filter blur(4px).
- Active item: opacity 1, translateY(0), blur(0). Transition ~450ms ease-out.
- Leaving item: moves up (translateY(-0.4em)) while fading out.
- Interval: 2600ms per phrase.
- Pause rotation when tab hidden (visibilitychange) or hero off-screen (IntersectionObserver).
- Optional: thin lime underline under the rotating phrase that shrinks to 0 and regrows on each swap (like a progress bar for the interval). Skip if it feels busy.

## Reduced motion
- @media (prefers-reduced-motion: reduce): no rotation, show "AI inside." statically.
- JS must check matchMedia('(prefers-reduced-motion: reduce)') before starting the interval.

## Mobile
